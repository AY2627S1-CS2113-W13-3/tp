# Kim Doyeon - Project Portfolio Page

## Overview

LabLog is a command-line application for laboratory technicians who lend
electronics equipment to students. It tracks equipment, borrowers, loans,
reservations and faults, and keeps every record in one validated local file.

### Summary of Contributions

**Enhancements implemented:**

* **Equipment model, entry point and registration** ([#16](https://github.com/AY2627S1-CS2113-W13-3/tp/pull/16),
  [#57](https://github.com/AY2627S1-CS2113-W13-3/tp/pull/57)): added `Equipment`, `Inventory` and the `LabLog` entry
  point, replacing the template placeholder, and the equipment registration
  flow. Registration rejects a duplicate asset ID before prompting for details
  and reports invalid details without stopping the console.
* **Equipment listing, filtering and sorting** ([#43](https://github.com/AY2627S1-CS2113-W13-3/tp/pull/43),
  [#101](https://github.com/AY2627S1-CS2113-W13-3/tp/pull/101),

  [#127](https://github.com/AY2627S1-CS2113-W13-3/tp/pull/127)): `list` with
  category, location and status filters and `sort/FIELD`. Filters and sorting
  work on a copy, so the stored inventory order never changes. Added the
  `unavailable` status for units with unresolved severe faults and documented
  the status precedence (lost, on loan, unavailable, available).
* **Equipment maintenance commands**: `copy` ([#102](https://github.com/AY2627S1-CS2113-W13-3/tp/pull/102)),
  `edit-equipment` ([#103](https://github.com/AY2627S1-CS2113-W13-3/tp/pull/103)),
  `move-equipment` ([#104](https://github.com/AY2627S1-CS2113-W13-3/tp/pull/104))
  and `find` ([#105](https://github.com/AY2627S1-CS2113-W13-3/tp/pull/105)).
  Edits keep the asset ID stable so loans and history stay attached, and a batch
  move validates every unit before changing any of them.
* **Partial-text search** ([#128](https://github.com/AY2627S1-CS2113-W13-3/tp/pull/128)):
  `search TEXT` matches names and models case-insensitively, keeps inventory
  order and shows live availability without changing records.
* **Aligned table output** ([#135](https://github.com/AY2627S1-CS2113-W13-3/tp/pull/135)):
  added `TableFormatter` and `Messages`, so listings print as aligned tables and
  successful changes start with `[OK]`. Converted reservations, waiting requests
  and the daily overview into tables, and rebuilt the `help` summary as a
  sectioned command table.
* **Integration fixes** ([#57](https://github.com/AY2627S1-CS2113-W13-3/tp/pull/57),
  [#59](https://github.com/AY2627S1-CS2113-W13-3/tp/pull/59)): restored the build and the
  active-loans error handling after merges, fixed routing of explicit equipment
  commands, and made the persistent console load shared borrower records on
