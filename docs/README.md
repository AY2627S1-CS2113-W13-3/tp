# LabLog

LabLog is a command-line application for laboratory technicians who manage
loanable electronics equipment. The main console supports equipment and borrower
registration, loans, renewals, single-unit and batch returns, active-loan listings, and
equipment history.
Equipment, borrowers, loans and renewal records persist together in the main
LabLog data file. A standalone borrower console is also
available.
