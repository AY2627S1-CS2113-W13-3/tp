# LabLog

LabLog is a command-line application for laboratory technicians who manage
loanable electronics equipment. The main console registers equipment and offers
help, history, and return handling. A separate borrower console registers and
saves borrowers and can list loans supplied to its handler.

Implementation is in progress: loan creation is not connected to either console,
and only borrower records persist across restarts. Returns and populated history
are tested with shared records supplied programmatically.
